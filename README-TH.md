# Social Science Arena — HUSO

เกมเปิดภาพจิ๊กซอว์ 10 ข้อสำหรับการเรียนรู้ทางสังคมศาสตร์ ใช้ HTML, CSS, Vanilla JavaScript และ Firebase Authentication / Cloud Firestore / Firebase Hosting

## ฟีเจอร์ในเวอร์ชันนี้
- ผู้เล่นเลือกชื่อเล่นและอิโมจิประจำตัวก่อนเข้าห้อง
- แผ่นเปิดภาพมีเอฟเฟกต์พลิก 3D และรูปทรงตกแต่งแบบชิ้นจิ๊กซอว์
- ตอบถูกแล้วเลื่อนไปข้อถัดไปทันที คะแนนสะสมตลอดเกม
- แต่ละข้อมีเวลานับถอยหลังและแถบ Progress bar
- เมื่อหมดเวลา ระบบไปข้อถัดไปโดยไม่ได้คะแนนข้อนั้น
- ผู้เล่นแต่ละคนมีความคืบหน้าของตัวเอง ไม่ต้องรอผู้เล่นคนอื่นตอบข้อเดียวกัน
- Host อยู่ในแดชบอร์ดตลอดการแข่งขัน ดูความคืบหน้า คะแนนล่าสุด และคะแนนรวมแบบเรียลไทม์
- Host กำหนดเวลาแต่ละข้อได้ 10–600 วินาที หยุดชั่วคราว เล่นต่อ ยกเลิก และเริ่มใหม่ในห้องเดิมได้
- เมื่อทุกคนทำครบ 10 ข้อ ระบบจบเกมและแสดงแท่นรางวัล 3 อันดับ
- หน้า Lobby มีแบนเนอร์สไลด์และวิดีโอเดิม

## ไฟล์สำคัญ
- `public/index.html` — แอปพลิเคชัน
- `public/assets/images/` — ภาพโจทย์และแบนเนอร์
- `public/assets/videos/social-science-lobby.mp4` — วิดีโอแบนเนอร์
- `firebase.json` — Firebase Hosting และ Firestore Rules path
- `firestore.rules` — กฎฐานข้อมูล

## Deploy
จากโฟลเดอร์โปรเจกต์:

```powershell
firebase use
firebase deploy --only hosting
```

หากต้องการใช้ Firestore Rules เวอร์ชันที่แนบมาด้วย ให้ตรวจสอบกฎและบัญชี Host ก่อน แล้วจึงรัน:

```powershell
firebase deploy --only firestore:rules
```

## ตั้งค่าบัญชี Host
โค้ดตัวอย่างยังใช้ `host123@gmail.com` เป็นอีเมล Host ในการแสดงเมนู Host และ Firestore Rules ด้วย ต้องเปลี่ยนอีเมลให้ตรงกับบัญชีผู้ดูแลจริงทั้งใน `public/index.html` และ `firestore.rules` ก่อนใช้งานจริง

## ข้อจำกัดและความปลอดภัย
- เวอร์ชันนี้เป็น prototype ฝั่ง client: การตรวจคำตอบและการบันทึกคะแนนเกิดจากเบราว์เซอร์ผู้เล่น ผู้ใช้ที่แก้โค้ดอาจปลอมคะแนนได้ จึงไม่ควรใช้กับการแข่งขันที่มีรางวัลหรือจำเป็นต้องป้องกันการโกงจนกว่าจะย้ายการตรวจคำตอบ/คำนวณคะแนนไป Firebase Cloud Functions หรือ backend ที่เชื่อถือได้
- Rules ที่แนบมาขยายสิทธิ์การอัปเดตความคืบหน้าและคะแนนเพื่อให้ฟีเจอร์ใหม่ทำงานได้ แต่ยังเปิดให้ผู้เล่นเขียนคะแนนของตนเองได้ใน prototype
- การหยุดเกมหยุด timer ฝั่ง client ไว้; การรีเฟรชหน้าอาจรีเซ็ตเวลาของข้อนั้น จึงควรเพิ่ม server-authoritative deadline หากต้องการความแม่นยำและป้องกันการโกงระดับ production
- ทดสอบ JavaScript syntax และตรวจสอบ ID ขององค์ประกอบ HTML แล้ว แต่ยังไม่ได้ทดสอบกับ Firebase project จริงหลัง deploy
